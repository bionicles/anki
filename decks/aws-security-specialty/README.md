The 427 cards include 5–10 independently reviewable prompts for each of the 70 numbered skills in the SCS-C03 guide. Questions revisit decisions under different constraints. For example, one KMS question asks how to route an SDK call privately, another asks how to require a specific endpoint, and a third asks what happens when the endpoint permits access but the key does not. Each answer includes an explanation and an AWS source.
